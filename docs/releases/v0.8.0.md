## 变更

- Claude 模型的思考档位改按模型记录：每个模型自己的模式（预算思考或自适应思考）、可用档位、能否关闭思考，替代此前统一的 `toggle/four/five` 预设。
- 表外的 Claude 模型 id 按族与版本推断档位；无法识别的 id 回退到预算思考并允许关闭。
- 需要预算思考的 Claude 路由自动写入 `thinkingBudgets`（low 1024、medium 4096、high 32000），与 kimi-code 的取值一致。
- Claude 表单新增「接受空思考签名」开关，落为路由级 `compat.allowEmptySignature`，默认关闭。

## 说明

- 「必须思考」的模型（Fable 5 系列）自适应开关保持开启且不可更改，与官方目录一致。
- 已保存的 Claude 提供商不会自动迁移：旧模型行保留原有推理档位，直到该行被重置或重新添加。
- 空签名开关默认关闭：官方 Anthropic API 拒绝空签名，只有会发出并接受空签名的中转端点才需要打开。
